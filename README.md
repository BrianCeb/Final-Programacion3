# Sistema de Control medico 

Sistema web para gestionar la medicación de pacientes en una residencia o consultorio.

La idea es que el médico indique los tratamientos de cada paciente, el sistema arme automáticamente la agenda de tomas del día y el personal de enfermería registre cada toma, dejando constancia de quién la dio y a qué hora.

>  Proyectoo — Final de Programación 3

## Tecnologías

- **Frontend:** React + Vite
- **Backend:** Node.js + Express
- **Base de datos:** MongoDB con Mongoose
- **Autenticación:** JWT


El frontend y el backend son proyectos independientes que se comunican por HTTP con JSON.

## Instalación


```bash
cd server
npm install
cp .env.example .env   

cd ../client
npm install
```
